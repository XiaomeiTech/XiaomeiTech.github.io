# 工业控制器

小美技术面向工业自动化、精密制造及复杂控制系统，提供**飞达控制器**与**行业定制控制器**两大类工业控制器产品。我们拥有从电路设计（PCB Layout）、嵌入式固件开发到结构设计的一站式业务能力，能够快速响应客户的个性化需求。

## 产品线

### 飞达控制器

面向高速供料与节拍控制场景，提供稳定的运动协同与现场联动能力。

- **CM-SC1524-N** — 5 轴脉冲控制卡，适配模切飞达、自裁自贴飞达及 SMT 供料飞达，配套 TSC-4827-143R 触摸显示屏。[查看详情](../feeder-controller/)

### 定制控制器

针对特定工艺场景深度定制的控制器与驱动器：

- **模块可分离式远程 I/O** — 一拖六分布式架构，适配多节点灯组传感场景
- **治具无线负压检测** — 高速线 / 低速线两档方案，实时监控负压临界报警
- **直驱伺服滚筒驱动器** — FOC 矢量控制，适配物流分拣、输送线与 AGV

## 与 Pexus 的关系

工业控制器与 **Pexus 标准自动化控制平台**互为补充：当标准产品无法完全匹配特定工艺时，小美技术可在既有技术底座上进行协议适配、I/O 扩展与专用算法集成等深度定制。

**合作流程**：需求沟通 → 方案评估 → 原型设计 → 样品验证 → 小批量试产 → 规模化供货。
