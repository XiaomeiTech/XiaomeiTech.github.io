# IM2610C EtherCAT 远程耦合器

## 产品概述

IM2610C 是一款基于 EtherCAT 工业以太网总线协议的远程耦合器，作为 EtherCAT 网络中的从站设备，负责将主站的控制指令转发至后级扩展模块，同时将扩展模块的 IO 状态实时反馈至主站。

### 核心特性

- 支持 EtherCAT 总线协议，CoE（CANopen over EtherCAT）应用层
- 标准 RJ45 通信接口，100BASE-TX 全双工
- 支持线型、星型、环型拓扑组网
- 分布式时钟（DC）同步，微秒级同步精度
- 导轨安装，适配标准 DIN 35mm 导轨
- 支持最大 32 个后级扩展模块

## 安装与接线

### 安装步骤

1. 将耦合器卡入 DIN 35mm 标准导轨，听到"咔嗒"声即锁定到位
2. 依次安装后级扩展模块，确保模块间连接器紧密扣合
3. 安装终端盖板

### 接线说明

::: caution 断电操作
接线前必须切断所有外部供电电源。
:::

1. 连接 EtherCAT 通信线缆（超 5 类及以上屏蔽双绞线）
2. 连接系统电源（24V DC）
3. 确保 PE 端子可靠接地
4. 上电前检查所有接线是否牢固
