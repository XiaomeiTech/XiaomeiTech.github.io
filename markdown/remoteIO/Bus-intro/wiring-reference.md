# 接线参考指南

## 接线前了解

### 简介

工业环境规范接线的核心原因是减小电磁干扰对设备和系统的影响，确保工业控制系统的稳定运行和数据的准确性。虽然工业产品在设计时已考虑恶劣环境因素，但在使用时仍需考虑外部的合理接线与走线。

### EMC 基本信息

电磁干扰源是客观存在的，只有在影响了敏感设备的正常工作时才构成"干扰"，构成干扰的三要素为：**干扰源**、**传输路径**和**敏感设备**。

EMC 问题属于系统问题，本章主要从传输路径方面介绍如何降低干扰的影响，常用的解决方法举例：屏蔽、隔离和合理布线。

不同的耦合方式需使用不同的处理方式，以下通过几种常见的耦合方式，介绍干扰产生原因和解决方法。

#### 共阻抗耦合

- **产生原因**：地线作为信号的回路路径之一，由于地线存在阻抗（约为几百 nH/m），A 系统上干扰致使地线存在电压差会叠加在 B 系统中。
- **解决方法**：分开单点接地。

#### 共电源耦合

- **产生原因**：电路 2 所需的电源电流任何变化都会影响电路 1，电路 2 的干扰容易串扰到电路 1 中。
- **解决方法**：
  - 电路 2 直接从电源输出端取电
  - 使用隔离变压器或滤波器等

#### 容性耦合

- **产生原因**：电容的本质为两个金属，中间加入某种介质；不同信号线平行走线，空气作为介质，从而产生了干扰之间的串扰导致容性耦合。
- **解决方法**：信号做屏蔽和拉开距离。

#### 感性耦合

- **产生原因**：电缆是一个电感，在变化的电流流过线缆时会在其周围产生磁场电场，磁场中敏感电路就会产生感应电压电流，对电路产生影响。
- **解决方法**：拉开间距减小互感和屏蔽线缆双端接地。

### 电缆布线要求

#### 布线要求

**主回路布线要求**

主回路电源线缆输入线、电机线缆会产生很强的电磁干扰，为了避免强干扰线缆与控制回路长距离并行走线耦合产生的电磁干扰，布线时主回路线缆与信号线缆间隔应大于 **30cm**。常见的主回路线缆有输入 RST 线、输出 UVW 线、直流母线及制动线缆，信号线缆有 IO 信号线和通信线。线缆线槽之间必须保持良好的连接且接地良好，铝制线槽可保证设备的等电位。PLC 和 IO 模块均应和系统（机械或装置）良好搭接，在安装的部分做好喷涂保护，导电金属充分接触。

**IO 信号布线要求**

IO 信号包括模拟量输入 AI 信号、模拟量输出 AO 信号、数字量输入 DI 信号、数字量输出 DO 信号和继电器输出信号。在进行 IO 信号线缆接线时，应与主回路接线（RST、UVW）及其它动力线或电力线分开至少 **30cm** 接线，否则会导致 IO 信号受到干扰。

#### 布线建议

**干扰电缆与敏感电缆布线**

传送不同类型信号的电缆，在布线时要分开，干扰电缆与敏感电缆间必须相距一定的距离，若布线空间足够，建议相隔 **30cm** 距离；若两种类型电缆必须交叉，则应当以**直角相交**的方式避免引起干扰。

**不同类型信号电缆布线**

建议不同类型信号电缆分开排布，且不同类型信号之间用等电位信号隔开。同一种类型信号的电缆排布，外层为等电位信号电缆，同时中间尽可能多考虑等电位信号排布。

**多芯电缆布线**

对于多芯电缆，建议一根电缆传送单一类的信号，如果需要用一根电缆传送不同类型的信号，则必须采用内部芯线屏蔽的电缆。

当用于连接设备的多芯电缆中有芯线剩余时，所有空着的（或备用的）导线应连接至等电位连接点（**禁止悬空放置**）。

**避免布线环路**

对于低电平传感器信号、有共用线的继电器类信号，应尽可能地将两条线靠近铺设，避免布线时形成环路面积；对于模拟信号，请务必使用**双绞线**，对于数字信号，需保证信号电缆之间靠近布线。

**多类电缆铺设方法**

多类电缆敷设时，电缆应始终沿着等电位连接的金属体敷设，不同类型的电缆之间尽可能隔开，可很大程度上改善内部的 EMC；同一个金属（锌铁或不锈钢）线槽内若用金属隔片隔开，效果则更好。

### 屏蔽线接地要求

屏蔽线可以减小磁场、电场或电磁场的干扰，将干扰电流从屏蔽层转移至地面上。

屏蔽电缆未屏蔽部分应当尽可能的短，屏蔽网接到最近的 PE 端，线缆若剥的过长，芯线容易受到信号干扰。对于没有专用 PE 端子的模块，屏蔽层可接到外部专用 PE 端子。

### 等电位接地要求

等电位接地可以将电气设备机体和外部导电部件连接到相同/近乎相同电位，此要求不仅可以防止电击，还可以满足 EMC 要求。

#### 接地总体要求

为了确保产品正确接地，请务必遵守以下要求：

- 请务必将接地端子接地，关于接地的方法，请遵照各国或各地区的相关电工法规；接地端子必须可靠接地，否则会导致设备工作异常甚至损坏；不可将接地端子和电源零线 N 端子共用。
- 请确认保护接地导体符合技术规格和当地的安全标准，并尽量缩短接地线长；保护接地导体必须采用**黄绿色铜导体线缆**，且不能串联断路器等开关设备。
- 要使用多个设备时，请遵循将所有设备接地的说明，不正确的设备接地会导致设备误操作。
- 推荐安装在导电金属面，保证设备整个导电底部与安装面良好接触。
- 接地螺钉的固定务必按照推荐的扭力矩进行固定，避免接地螺钉松动或过紧。

#### 多设备接地要求

| 序号 | 接线说明 |
|------|---------|
| ① | 产品主回路输入 PE 端子通过保护接地导体连接到控制柜接地铜排 |
| ② | 将输入电源端 PE 线缆连接到控制柜接地铜排 |
| ③ | 将控制柜接地铜排通过保护接地导体连接到控制柜金属机壳 |
| ④ | 电机输出电缆屏蔽层连接到产品输出 PE 端子 |

#### 机柜接地要求

在机柜内抑制干扰比较经济有效的措施是确保在安装时将干扰源与可能被干扰的设备进行隔离。根据干扰源的强弱需要将电柜分成多个 EMC 区域或者分成多个机柜，规则如下：

| 序号 | 接地规则 |
|------|---------|
| ① | 请将控制部分设备与驱动部分设备分别放置于两个单独的机柜 |
| ② | 多个机柜形式时，机柜之间应采用横截面积至少 **16mm²** 的接地线进行连接，以实现机柜间的等电位 |
| ③ | 在一个机柜中应根据信号强弱进行分区布放 |
| ④ | 机柜中不同区域设备应进行等电位连接 |
| ⑤ | 从机柜中引出的所有通信（例如 RS485）和信号线缆需做好屏蔽 |
| ⑥ | 机柜中电源输入滤波器应放置在靠近机柜输入接口位置 |
| ⑦ | 机柜中各接地点位置应做好喷涂保护 |

### 避雷和过压保护

SPD 浪涌抑制器适用于 IO 模块的输入侧，保证电气系统和重要的电气电子设备免遭雷击过电压的损坏。

SPD 主要用来限制在电源和信号系统中由雷电引起的瞬态过电压和大部分的操作过电压。雷电电涌可以通过电源或信号线路侵入 IO 模块，可以由于雷击时地电位升高反击设备，也可以因雷击建筑物本身或在附近产生的脉冲电磁场在电缆和环路中感应产生。因此，除了配备良好的避雷针、引地线和接地装置等外部防雷措施，还需要安装 SPD 浪涌抑制器，因为外部防雷措施无法防止雷电感应电涌沿线的传导侵入和雷电二次回击。

## 连接通信线缆

### 接线注意事项

连接通信线缆时请注意以下事项：

- 请选用推荐线缆及转接板连接，扩展线缆建议选用屏蔽线缆提高抗干扰能力。
- 将电缆连接到本产品 Ethernet / EtherCAT / PROFINET 网口时，请牢固地插入网口，直到其锁定到位。
- 请勿将通信线缆与动力线（高电压，大电流）等传输强干扰信号的电缆捆在一起，应该分开走线并且避免平行走线。
- 请勿将通信电缆放置在产生噪音的设备附近，如果必须放置在有噪音的设备附近，请采取措施解决噪音问题，例如将设备放置在金属外壳中。
- 请勿将通信电缆放置在高温或高湿度的环境。
- 请勿将通信电缆放置在灰尘、油雾或其他有害因素较多的环境。
- 通信电缆的弯曲半径存在限制，请检查通信电缆规格的弯曲半径。

### 接线前准备

#### 线缆要求

EtherCAT 总线、EtherNet/IP 总线和 PROFINET 总线采用标准 RJ45 网络接口与标准水晶接头，请使用超 5 类及以上屏蔽双绞线，带铁壳注塑线。采用屏蔽层网线进行网络数据传输，无短路、错位和接触不良现象，带屏蔽层网线规格要求如下：

| 项目 | 规格 |
|------|------|
| 电缆类型 | 弹性交叉线缆，双层屏蔽（SFTP 或 SFTPP），超 5 类及以上线缆（100BASE-TX） |
| 双层屏蔽 | 纺织网屏蔽层（覆盖率 85%）、铝箔屏蔽层（覆盖率 100%） |
| 符合标准 | EIA/TIA568A、EN50173、ISO/IEC11801、EIA/TIA Bulletin TSB、EIA/TIA SB40-A & TSB36 |
| 导线截面 | AWG26 及以上 |
| 导线类型 | 双绞线 |
| 线对 | 4 |
| 认证 | UL |
| 环境 | 耐工业机油、耐酸碱腐蚀；工作环境温度：-30℃ ～ +60℃ |

> **重要**：设备之间电缆的长度不能超过 **100m**，超过该长度会使信号衰减，影响正常通信。

### 连接和拆卸线缆

#### 连接线缆

用手指捏住水晶头，沿着网口方向插入网线，直至发出"喀擦"声。

> **注意**：连接线缆时务必确保从上一个设备的输出端口连接至下一个设备的输入端口，如果接错将不能正常通信。

#### 拆卸线缆

按住水晶头尾部机构将连接器与网口呈水平方向拔出。

## 连接电源和地线

### 接线注意事项

连接电源线缆时请注意以下事项：

- 接线前，请先将外部供应电源断电。
- 电源线缆布线时，避免与动力线（高电压，大电流）等传输强干扰信号的电缆捆在一起，应该分开走线并且避免平行走线。

### 接线前准备

建议使用 3 芯非屏蔽线，最大使用长度为 **20 米**。

管型线耳适配线径参考：

| 国标（mm²） | 美标（AWG） |
|------------|------------|
| 0.3 | 22 |
| 0.5 | 20 |
| 0.75 | 18 |
| 1.0 | 18 |
| 1.5 | 16 |

> 如使用其他管型线耳，请将其压接到绞线，确保形状和尺寸符合要求。

### 连接和拆卸线缆

电源端子采用按压式设计，拆卸线缆前需先按压端子释放部件，再进行拆卸线缆。

**连接线缆**：将线缆插入电源端子即可。

**拆卸线缆**：

1. 使用一字螺丝刀按压端子释放部件。
2. 将线缆从电源端子拔出。

## 连接 USB 线缆

本产品可通过 USB 线缆直接连接安装编程软件或配置工具的 PC 机，进行固件升级。

**前提条件**：已准备一根 USB 线缆和一台 PC 机。

**操作步骤**：将 USB 线缆一端插入本产品 Type-C 端口，另一端连接至 PC 机。如需拆卸线缆，直接往外拔出 USB 线缆即可。

---

## 连接 PUSH IN 线缆

**连接线缆**：将线缆插入 PUSH IN 端子。

**拆卸线缆**：

1. 使用一字螺丝刀按压端子释放部件。
2. 将线缆从 PUSH IN 端子拔出。
