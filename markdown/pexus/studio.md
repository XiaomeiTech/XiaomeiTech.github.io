# Pack Studio 集成开发环境

**Pack Studio** 是 Pexus 标准自动化控制平台的**集成开发环境（IDE）**，用于对 Pexus PAC 与 Pexus Edge 进行工程组态、逻辑编程、参数配置、调试与诊断。Pack Studio 面向工程师的日常开发，提供从"新建工程"到"上线运维"的一体化体验。

## 定位

- **一个工程入口**：硬件组态、控制逻辑、通信配置与监控诊断在同一环境中完成；
- **与 Pack Runtime 协同**：工程经编译后下载至目标设备的 Pack Runtime 执行，支持在线监控与调试；
- **面向 Pexus 全系**：同时覆盖 PAC 控制器与 Edge 远程 I/O，工程结构统一。

## 功能概览

| 能力 | 说明 |
|------|------|
| **工程管理** | 新建/导入/版本化管理自动化工程 |
| **硬件组态** | 可视化配置 Pexus PAC、Pexus Edge 耦合器与扩展模块 |
| **逻辑编程** | 面向控制的编程与组态（IEC 61131-3 风格，以发布版本为准） |
| **通信配置** | 现场总线（EtherCAT、PROFINET 等）与上位接口的参数化配置 |
| **在线调试** | 变量监控、强制、断点与执行状态跟踪 |
| **诊断与日志** | 设备状态、报警与运行日志统一呈现 |
| **固件管理** | 控制器与 I/O 模块的固件升级维护 |

## 典型工作流

```mermaid
graph LR
    A[新建工程] --> B[硬件组态<br/>PAC + Pexus Edge]
    B --> C[编写控制逻辑]
    C --> D[编译并下载]
    D --> E[在线调试与监控]
    E --> F[交付与运维]
```

## 核心特性

- **统一工程视图**：控制器、远程 I/O 与通信配置集中管理，减少多工具切换成本；
- **所见即所得的组态**：以图形化方式搭建设备拓扑，配置结果与运行状态一致呈现；
- **可维护性优先**：工程结构清晰、变量命名规范，支持多人协作与历史追溯；
- **随平台演进**：与 Pexus PAC / Pexus Edge / Pack Runtime 同步迭代，持续增强。
