# 产品命名规则

::: tip 所属系列
本命名规则适用于 **Pexus Edge** 远程 I/O 系列（通讯耦合器 IM 系列与扩展模块 EM 系列）。系列总览请见 [Pexus Edge 分布式远程 I/O](../)。
:::

## 命名结构总览

```
 IM    2    6    10    C
 │     │    │    │     │
 │     │    │    │     └── 后缀：产品类型标识
 │     │    │    └──────── 型号变体码
 │     │    └───────────── 产品类别码
 │     └────────────────── 总线协议族
 └──────────────────────── 产品大类
```

---

## 逐段解析

### 1. 前缀 `IM` / `EM`

| 前缀 | 全称 | 含义 |
|------|------|------|
| **IM** | Interface Module | 通讯耦合器，负责总线通信与主站交互 |
| **EM** | Extension Module | 扩展 IO 模块，挂在耦合器后面的信号模块 |

### 2. 总线协议族（第1位数字）

| 数字 | 协议 | 代表产品 |
|------|------|---------|
| `1` | PROFINET | IM**1**620-PN |
| `2` | EtherCAT | IM**2**620-EC / IM**2**610C |
| `3` | EtherNet/IP | IM**3**620-EIP |
| `4` | ModbusTCP | IM**4**620-MT |

### 3. 产品类别（第2位数字）

| 数字 | 类别 | 说明 |
|------|------|------|
| `6` | 耦合器 (Coupler) | 所有 IM 系列的通讯耦合器均为 `6` |

### 4. 型号变体（第3~4位数字）

| 编码 | 含义 |
|------|------|
| `20` | 标准版，带总线后缀（如 `-EC`、`-PN`） |
| `10` | 定制版，后缀简化为单字母 `C`（Custom，客户定制） |

### 5. 后缀

| 后缀 | 协议 | 示例 |
|------|------|------|
| `-PN` | PROFINET | IM1620-**PN** |
| `-EC` | EtherCAT | IM2620-**EC** |
| `-EIP` | EtherNet/IP | IM3620-**EIP** |
| `-MT` | ModbusTCP | IM4620-**MT** |
| `C` | Custom（客户定制） | IM2610**C** — 客户定制版 |

## 扩展模块 EM 命名

```
 EM    X    Y    ZW
 │     │    │    │
 │     │    │    └── 系列变体码
 │     │    └─────── 通道密度：1=8ch, 2=16ch, 4=32ch
 │     └──────────── 信号类型：1=DI, 2=DO, 5=AO, 6=AI
 └────────────────── 扩展模块 (Extension Module)
```

### 信号类型码

| 编码 | 信号类型 | 示例 |
|------|---------|------|
| `1` | DI（数字量输入） | EM**1**130 |
| `2` | DO（数字量输出） | EM**2**110 |
| `5` | AO（模拟量输出） | EM**5**140 |
| `6` | AI（模拟量输入） | EM**6**140 |

| 型号 | 信号类型 | 通道 | 备注 |
|------|---------|------|------|
| EM1130 | DI 数字量输入 | 8 | — |
| EM1230 | DI 数字量输入 | 16 | — |
| EM1430 | DI 数字量输入 | 32 | — |
| EM2110 | DO 数字量输出 | 8 | — |
| EM2210 | DO 数字量输出 | 16 | — |
| EM2410 | DO 数字量输出 | 32 | PNP 型 |
| EM2420 | DO 数字量输出 | 32 | NPN 型 |
| EM5140 | AO 模拟量输出 | 8 | — |
