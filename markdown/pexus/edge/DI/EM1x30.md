# EM1x30 数字量输入模块

32 / 16 通道 · 双向输入

本页以 **32 通道版本 EM1430** 为例讲解，同时适用于 **16 通道版本 EM1230**。系列名称中的 `x` 为通道数代码：`4` 表示 32 通道，`2` 表示 16 通道。

16 通道版本参照本页的通用说明使用，接线和通道配置以实际产品的 16 路端子定义为准。
