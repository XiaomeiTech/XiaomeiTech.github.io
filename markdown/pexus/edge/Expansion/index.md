# 耦合器与扩展模块选型

IM 通讯耦合器与 EM 背板总线扩展模块统一选型。按模块类型、通道数、信号或协议筛选，也可直接搜索型号。

<IoSelectionTable />

混合型模拟量模块的“4+4”表示 4 路电流 + 4 路电压，共 8 通道。

数字量模块同一电气类型、同一性能版本的 32 通道与 16 通道型号共用一份系列文档，默认以 32 通道版本讲解。例如，EM2420P 与 EM2220P 共用 [EM2x20P 系列说明](../DO/EM2x20P.md)。选型表保留各具体型号，点击后进入对应的系列文档。

## 产品命名规则

**IM** 为通讯耦合器，**EM** 为背板总线扩展模块。下表说明 EM 型号的功能、通道数、电气类型和后缀。

| 位置 | 编码含义 |
| :--- | :--- |
| 第 1 位：功能 | `1` DI 数字量输入；`2` DO 数字量输出；`5` AO 模拟量输出；`6` AI 模拟量输入 |
| 第 2 位：通道数 | `1` 8 通道；`2` 16 通道；`4` 32 通道 |
| 第 3 位：电气类型 | `1` PNP 型；`2` NPN 型；`3` 双向输入；`4` 电流；`5` 电压；`6` 电流 / 电压混合；`7` 电流 / 电压可配置（AO） |
| 末尾后缀 | 带 `P` 为性能型，选型表中显示“性能型”；不带 `P` 为普通型，显示 `-` |

例如 **EM1430**：背板总线扩展模块，DI 数字量输入，32 通道，双向输入，普通型。**EM1430P** 为对应的性能型，选型表在行首以模块颜色渐变标识。

系列文档名称中的 `x` 代表通道数代码：`4` 为 32 通道，`2` 为 16 通道。例如 **EM2x20P** 包含 **EM2420P（32 通道）**与 **EM2220P（16 通道）**，订购和组态时使用具体型号。

IM 耦合器同样分为普通型和性能型，`P` 位于数字型号之后、协议后缀之前。例如 **IM2620-EC** 为普通型，**IM2620P-EC** 为性能型；`-EC`、`-EIP`、`-PN`、`-MT` 为协议后缀。
