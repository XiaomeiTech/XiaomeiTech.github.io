# Modbus 耦合器（Pexus Edge）

<ModuleBadge kind="IM" label="IM · Modbus" />

Modbus 耦合器是 **Pexus Edge** 远程 I/O 系列中面向 Modbus 总线的通讯耦合器，支持 Modbus TCP 与 Modbus RTU 双模式，兼容主流 HMI、SCADA 与各类 PLC，部署简单、运维便捷，并向下挂接扩展模块。
