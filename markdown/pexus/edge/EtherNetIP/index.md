# EtherNet/IP 耦合器（Pexus Edge）

<ModuleBadge kind="IM" protocol="EIP" label="IM5620-EIP" />

**IM5620-EIP** 是 **Pexus Edge** 远程 I/O 系列中面向 EtherNet/IP 总线的通讯耦合器，基于 CIP 协议与罗克韦尔等主流 PLC 无缝对接，支持隐式 I/O 与显式报文通信，并向下挂接扩展模块。
