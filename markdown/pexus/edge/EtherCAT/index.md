# EtherCAT 耦合器（Pexus Edge）

EtherCAT 耦合器是 **Pexus Edge** 远程 I/O 系列中面向 EtherCAT 总线的通讯耦合器，作为 EtherCAT 网络从站实现主站指令下发与现场 I/O 状态实时回传，支持级联扩展模块，提供微秒级确定性响应。
