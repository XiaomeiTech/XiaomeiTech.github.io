# WM9232 无线网关（Pexus Edge）

## 产品概述

WM9232 是 **Pexus Edge** 无线远程 I/O 系列中的 2.4G 无线网关，用于接收现场 WM9832 等无线节点的 2.4G 私有协议数据，并作为 **ModbusTCP 从站**将数据上送 PLC / 上位系统。网关单信道接入，可管理多路无线节点，实现载具、工位等分布式现场的无线数据汇聚。相较于标准蓝牙连接场景常见的 8 设备连接上限，WM9232 基于 2.4G 私有协议不受该限制，可接入更多无线节点。

网关通讯核心采用高集成度、低功耗 2.4GHz 无线射频芯片（CH592），物理层复用 Bluetooth Low Energy（BLE 5.4）标准调制解调规范，链路层采用基于底层 RF_PHY 接口的深度定制 2.4G 私有协议，与 WM9832 等无线 IO 模块同平台互通。

## 接线与使用

### 电源接线

使用 DC 22~26V 电源模块，参照电源端子定义接好电源并可靠接地。

::: caution 断电操作
接线前必须切断所有外部供电电源。
:::

### 以太网接线

采用标准 RJ45 网络接口，经交换机或直连接入机台 PLC 所在的以太网络，PLC 作为 ModbusTCP 主站轮询网关。

::: notice 注意事项
- 推荐使用类别 5 或更高等级的双屏蔽（编织网+铝箔）STP 电缆作为通讯电缆；
- 设备之间线缆长度不超过 100m。
:::
