# NPN 型 DO 接线与供电注意事项

本说明适用于本系列 NPN 型（低边）数字量输出模块，说明输出关闭后仍可能存在负载电流的原因，以及接线和上下电要求。

以 32 通道版本为例说明，16 通道版本遵循相同的供电与操作要求，按实际产品的 16 路端子定义接线。系列文档见 [EM2x20](./EM2x20.md) 和 [EM2x20P](./EM2x20P.md)。

> **使用要求：模块输出侧电源与对应负载必须配套供电、配套断电。软件关闭输出或仅断开模块输出侧电源，都不能作为负载已完全断电的依据。**

## 输出如何控制负载

NPN 型输出通过接通负载到公共地的回路来控制负载。正常供电时，电流路径为：

```text
电源正端 → 负载 → 输出端 → 内部输出开关 → 输出侧公共地 → 电源 0 V
```

输出开启时，内部开关接通，负载获得工作电流；输出关闭时，内部开关断开这条受控回路。

这里的“输出侧电源”是为模块现场输出电路供电的电源。控制器或通信部分有电，并不代表输出侧电源已经正确接入。

## 为什么断开模块电源后，负载仍可能有电流

输出电路内设有续流保护通路，用于在继电器、电磁阀等感性负载关闭时释放储存的能量、限制电压冲击。**这条保护通路不会随软件关闭输出而被切断。**

如果只断开模块输出侧电源的正端，而负载正端仍连接着外部电源，输出端电压就可能高于模块内部电源电压。当满足保护通路的导通条件时，电流会经输出端反向进入模块内部，形成“反向供电”：

```text
仍带电的负载电源正端
    ↓
   负载
    ↓
  输出端
    ↓
内部续流保护通路
    ↓
模块内部电源及用电电路
    ↓
输出侧公共地 → 负载电源 0 V
```

因此，即使所有输出都已设为关闭，负载仍可能有电流，模块内部也可能被反向供电而带有电压。对于 LED 等对小电流敏感的负载，可能表现为关断后仍有亮光。

只要负载电源仍接通，且模块内部存在持续消耗电流的回路，这种电流就可能一直存在，不能简单理解为电容充电或关断瞬间的短暂现象。电流大小取决于负载和实际接线，不能据此认定模块正常供电，也不能将其作为正常关断漏电流指标。

## 正确接线

以 24 V 系统为例，建议模块输出侧电源与对应负载使用**同一受控供电支路**，在共同的断电开关之后分别接入模块与负载。

| 接线对象 | 连接要求 |
| :--- | :--- |
| 模块输出侧电源正端 | 接受控支路的 +24 V |
| 对应负载正端 | 接同一受控支路的 +24 V |
| 负载另一端 | 接对应的 DO 输出端 |
| 模块输出侧公共地 | 与负载电源 0 V 可靠连接 |

端子名称、位置及允许的电压、电流范围以产品接线定义和规格为准。公共地与电源正端不可混接。

**共用同一台电源，也要保证配套断电。** 如果负载接在断电开关之前，而模块接在开关之后，关闭开关时仍会形成“模块掉电、负载带电”的状态。

## 上下电与使用注意事项

1. **正常运行时，保持输出侧电源连接可靠。** 不要只连接公共地和输出线，而遗漏模块输出侧电源正端。
2. **停机断电时，同时切断对应负载供电。** 不要只关闭软件输出、停止通信或断开模块电源，却让负载继续带电。
3. **必须分步上电时，先接通模块输出侧电源，再接通负载电源；分步断电时，先断开负载电源，再断开模块输出侧电源。**
4. **检修、接线或拆卸前，切断模块和负载的相关电源，并确认已无电压。** 不以输出状态显示或模块指示灯熄灭作为断电依据。
5. **独立供电或存在单独掉电可能时，需要配套硬件措施。** 应通过经过验证的负载侧断电、供电联锁或隔离方案，避免模块输出侧失电时负载继续向其反向供电；软件关断不能替代这些措施。
6. **不要以负载“没有明显动作”判断接线正确。** LED 亮光、测得电流或模块残留电压都需要检查供电关系；继电器、电磁阀等负载也不能按小电流灯负载的现象推断可长期使用。

## 关闭输出后仍有电流时，先检查什么

先切断模块及对应负载供电，再检查模块输出侧电源正端是否漏接、松脱，负载是否接在另一条持续带电的支路，以及断电开关是否同时覆盖模块与负载。修正供电关系后，再按上述顺序恢复供电并确认输出动作。

如果供电和接线均正确，关闭输出后仍有异常电流，应结合实际负载继续排查。不要仅凭这一现象判断为程序没有关闭输出，也不要通过反复下发关闭指令代替接线检查。
