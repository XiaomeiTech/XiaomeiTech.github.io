# DO 数字量输出模块

用于输出现场数字量控制信号，通过背板总线与 IM 耦合器交换数据。

## 系列文档

16 通道与 32 通道共用一份系列说明，默认以 32 通道版本讲解。型号中的 `x=4` 表示 32 通道，`x=2` 表示 16 通道。

| 输出类型 | 普通型 | 性能型 |
| :--- | :--- | :--- |
| PNP 型 | [EM2x10](./EM2x10.md) | [EM2x10P](./EM2x10P.md) |
| NPN 型 | [EM2x20](./EM2x20.md) | [EM2x20P](./EM2x20P.md) |

## NPN 型输出使用注意事项

NPN 型输出的内部续流保护通路可能在模块输出侧失电、负载仍带电时形成反向供电，使关闭的负载仍有电流。因此，模块输出侧电源与对应负载应配套供电、配套断电，不能用软件关闭输出代替负载断电。
